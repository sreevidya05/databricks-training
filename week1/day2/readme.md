# Employee Database SQL Practice – Day 2

## Project Overview

This repository contains Day 2 SQL practice queries created using an Employee database in MySQL.  
The purpose of this practice is to strengthen SQL fundamentals by performing different database operations such as filtering, grouping, sorting, and pattern matching.

---

## Tools and Technologies

- MySQL 5.7
- DB Fiddle

---

## Topics Practiced

### 1. SELECT Statements
Used to retrieve complete and specific records from the table.

### 2. WHERE Clause
Used to filter employees based on salary, city, department, and experience.

### 3. GROUP BY Clause
Used to group records department-wise and city-wise.

### 4. HAVING Clause
Used to filter grouped results using aggregate conditions.

### 5. DISTINCT Keyword
Used to display unique values from columns.

### 6. ORDER BY and LIMIT
Used to sort records and display top results.

### 7. SQL Operators Used
- Comparison Operators
- Logical Operators
- IN and NOT IN
- BETWEEN
- LIKE Operator

---

## Operations Performed

- Display all employee details
- Find employees from specific departments
- Retrieve employees based on salary conditions
- Count employees city-wise
- Calculate department-wise average and total salary
- Display top highest paid employees
- Search employee names using pattern matching

---
## Learning Outcomes

This SQL practice helped in understanding:

- Data retrieval techniques
- Filtering records using conditions
- Aggregate functions and grouping
- Sorting and limiting records
- Using operators for advanced queries
- Pattern matching using LIKE
