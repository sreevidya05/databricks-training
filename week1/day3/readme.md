# Week 2 - SQL Joins Practice

## Aim

The aim of this assignment is to practice SQL JOIN concepts by working with students, courses, enrollments, and instructors tables.

## Activities Completed

- Wrote queries using LEFT JOIN to include unmatched rows
- Used RIGHT JOIN for enrollment information
- Simulated FULL OUTER JOIN using UNION
- Identified missing instructor assignments
- Generated combined reports from multiple tables
- Practiced CROSS JOIN operations

## SQL Concepts Practiced

- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN
- CROSS JOIN
- UNION
- Filtering with NULL values

## Learning Outcome

Gained practical knowledge on handling relationships between tables and retrieving both matched and unmatched data using SQL joins.
