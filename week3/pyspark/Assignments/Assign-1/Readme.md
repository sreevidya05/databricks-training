# PySpark DataFrame Operations

This project demonstrates basic PySpark DataFrame operations using an employee dataset.

## Topics Included

- Select
- Alias
- Filter / Where
- withColumnRenamed
- withColumn
- Type Casting
- Sort / OrderBy
- Limit

## Technologies Used

- Python
- PySpark
- Apache Spark

## Dataset Columns

- emp_id
- emp_name
- age
- city
- designation
- salary
- joining_date
- department

## Operations Performed

### SELECT
- Selecting single and multiple columns
- Selecting columns with conditions

### ALIAS
- Renaming columns using alias()

### FILTER / WHERE
- Filtering records using conditions
- Using AND, OR, BETWEEN, STARTSWITH, and ENDSWITH

### WITHCOLUMNRENAMED
- Renaming DataFrame columns

### WITHCOLUMN
- Creating calculated and derived columns
- Using functions like when(), concat_ws(), year(), and substring()

### TYPECASTING
- Converting columns into different datatypes

### SORT / ORDERBY
- Sorting records in ascending and descending order

### LIMIT
- Displaying limited number of rows
